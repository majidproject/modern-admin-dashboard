# Modern Admin Dashboard ⚡️

A responsive admin dashboard built with **Next.js 15**, **TypeScript**, and **Tailwind CSS**, focused on clean structure, reusable components, and modern dashboard UX.

## Features

* Responsive dashboard layout
* Dark and light mode
* Interactive charts with Recharts
* Data tables with pagination and status indicators
* Settings forms
* Collapsible sidebar and mobile navigation
* Reusable dashboard components

## Tech Stack

* Next.js 15
* TypeScript
* Tailwind CSS
* Recharts
* Lucide React
* next-themes

## Getting Started

Clone the repository:

```bash
git clone https://github.com/majidproject/modern-admin-dashboard.git
cd modern-admin-dashboard
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```
